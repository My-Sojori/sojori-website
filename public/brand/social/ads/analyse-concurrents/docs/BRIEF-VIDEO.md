# Brief vidéo pub — Lead magnet « Analyse concurrentielle » Sojori

## Objectif
Vidéo courte (format vertical 1080×1920, ~15–20 s) pour pub Meta (Instagram/Facebook, Maroc).
But : montrer en accéléré ce que fait l'outil gratuit d'analyse concurrentielle, pour pousser au clic vers `business.sojori.com/fr/analyse-concurrents`.

## Ton & marque
- Univers Sojori : fond clair, dégradé doré (gold), typo moderne, glassmorphism léger.
- Rythme rapide, chaque étape ~2–3 s, transitions texte fluides (fade/slide).
- Langue : français.

## Données (RÉELLES, anonymisées)
Fichier : `video-data-anon.json` (mêmes chiffres qu'une vraie analyse AirROI, noms d'annonces renommés).
⚠️ NE PAS afficher les mots « AirROI » ni « Sonnet »/« Claude » nulle part.
⚠️ Les `photoUrl` du JSON pointent vers des CDN Airbnb réels → **ne pas afficher les vraies photos** (risque d'identifier l'hôte). Utiliser des placeholders/illustrations ou flouter.

## Scénario (6 étapes + CTA)

1. **Intro / hook** (~2 s)
   Texte plein écran : « Votre Airbnb gagne-t-il autant qu'il pourrait ? »
   Sous-titre : « Collez votre lien. On analyse le marché. »

2. **Estimation prix** (~3 s) — animation de comptage
   - « Votre revenu estimé » → **223 960 MAD/an** (compteur qui monte)
   - « Prix marché » → **1 190 MAD/nuit**, basé sur **20 concurrents**

3. **Récupération calendrier** (~2 s)
   Animation d'un calendrier qui se remplit (343 jours), badge « Occupation : 71 % ✓ »
   Texte : « On lit votre calendrier réel. »

4. **Concurrents** (~3 s)
   Apparition d'une grille/carte de **20 concurrents** autour de vous (points sur une mini-carte radar ou cartes qui s'empilent).
   Texte : « 20 annonces comparables analysées. »

5. **Comparaison avec le meilleur** (~3 s)
   Face-à-face « Vous » vs « Le meilleur concurrent » :
   | | Vous | Meilleur concurrent |
   |---|---|---|
   | Prix/nuit | 837 MAD | 2 092 MAD |
   | Occupation | 71 % | 48 % |
   | Revenu/an | 223 960 MAD | 372 470 MAD |
   Punchline animée : **« +148 510 MAD/an laissés sur la table »** (chiffre qui pulse en gold).

6. **Note / bilan** (~3 s)
   Carte « Bilan Sojori » : « Superhost 4,94★ avec piscine, mais prix 60 % sous le premium du quartier. »
   → 1 action clé : « Montez vos prix aux dates fortes. »

7. **CTA final** (~2 s)
   Logo Sojori + « Analyse gratuite de VOTRE annonce »
   Bouton : « business.sojori.com » · « Résultat instantané »

## Contraintes
- Aucune donnée d'un hôte réel identifiable (noms déjà anonymisés dans le JSON, photos à ne pas utiliser telles quelles).
- Chiffres = tels quels dans le JSON (crédibilité).
- Export : MP4 vertical 1080×1920, + une variante carrée 1080×1080 si possible.
